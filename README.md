# RetailIQ — Sales & Inventory Copilot

Clean, stable React + Vite hackathon prototype.

## Run
1. Extract the ZIP.
2. Open the extracted `RetailIQ_Clean` folder in VS Code.
3. Terminal: `npm install`
4. Terminal: `npm run dev`
5. Open the exact `Local:` address printed by Vite.

## Included
Dashboard, AI Copilot, Billing/POS, 48 preloaded products, 3 stores, inventory health, sales analytics, gross profit/loss view, multi-store transfer, alerts, what-if simulator, reports/export, search, responsive dark UI and localStorage persistence.

The Copilot is a local rule-based evidence engine, not an external paid LLM. The prototype intentionally refuses to calculate net profit when operating expenses are unavailable.
